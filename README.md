# چی بپزم؟ — نسخهٔ PWA

نسخهٔ آمادهٔ آپلود در GitHub و انتشار با GitHub Pages، با manifest کامل، آیکون‌های PNG، اسکرین‌شات‌های معرفی و پشتیبانی آفلاین.

## فایل‌ها

- `index.html` — ساختار صفحه
- `style.css` — استایل‌ها
- `script.js` — منطق برنامه و داده‌های غذاها
- `manifest.json` — تنظیمات نصب، آیکون، orientation، دسته‌بندی و screenshots
- `sw.js` — کش و پشتیبانی آفلاین
- `icons/` — آیکون‌های ۱۹۲ و ۵۱۲ پیکسلی
- `screenshots/` — تصاویر معرفی نسخهٔ دسکتاپ و موبایل

بعد از Extract، همهٔ محتویات را در ریشهٔ Repository قرار بده و GitHub Pages را روی branch `main` و پوشهٔ `/root` فعال کن.
