# چی بپزم؟ — نسخهٔ PWA

این نسخه برای آپلود در GitHub و انتشار با GitHub Pages آماده است.

## فایل‌ها

- `index.html` — ساختار صفحه
- `style.css` — استایل‌ها
- `script.js` — منطق برنامه و داده‌های غذاها
- `manifest.json` — تنظیمات نصب به‌عنوان اپلیکیشن
- `sw.js` — کش و پشتیبانی آفلاین

فایل آیکون جداگانه عمداً اضافه نشده است. برای فعال شدن Service Worker، برنامه باید روی HTTPS اجرا شود؛ GitHub Pages این شرط را فراهم می‌کند.
